## 📸 Adding Your Personal Photos & Custom Music

### Adding Photos:
1. Open the folder: `public/photos/`
2. Add your 5 photographs:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`
   - `photo5.jpg`
3. Refresh the browser—they will appear automatically!

### Adding Background Music:
1. Open the folder: `public/music/`
2. Add your favorite romantic audio file:
   - `romantic-track.mp3`

## 🚀 Running Locally & Vercel Deployment

1. **Start development server**:
   ```powershell
   npm run dev
   ```
2. **Open in browser**:
   - Local: `http://localhost:5173/`
   - Mobile Wi-Fi: `http://10.160.79.145:5173/`

3. **Deploy to Vercel**:
   ```powershell
   git add .
   git commit -m "Advanced cinematic birthday upgrade for Naga Maneesha Reddy ❤️"
   git push origin main
   ```
   Import into [vercel.com](https://vercel.com) and click **Deploy**.
