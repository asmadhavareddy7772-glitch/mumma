HOW TO ADD YOUR ROMANTIC BACKGROUND MUSIC:

1. Copy your romantic instrumental or song file into this folder: `public/music/`
2. Name it:
   - romantic-track.mp3
   (or song.mp3 / background.mp3)
3. If no music file is added, the website automatically plays a soothing built-in acoustic chime/music-box melody using Web Audio API!
4. The music player is fixed at the bottom-right corner, does NOT autoplay (starts only when she clicks play), and includes an equalizer animation.
